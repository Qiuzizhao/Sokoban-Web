# Third-party dependencies

The bundled browser code includes:

- miaoda-game-sokoban-core 0.1.1: MIT.
- miaoda-game-grid-core 0.3.2: MIT.
- miaoda-game-serialization-core 0.1.0: MIT.
- miaoda-game-random-core 0.1.0: MIT.
- lucide 0.468.0: ISC, with some icons derived from Feather (MIT).

The available license files and the published package metadata (including license declarations) are copied to `web/licenses/`. The miaoda packages declare MIT in their metadata but do not ship standalone license files in their npm distributions.

The original game assets and levels were extracted from the user-provided executable. Their ownership and license are separate from the third-party libraries above.
