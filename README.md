# 推箱子网页版

打开 `web/index.html` 即可游玩，无需安装、联网或运行 BCM 播放器。

也可以直接打开根目录的 `推箱子单文件版.html`，只需这一个文件。它内嵌样式、代码、50 个关卡、全部网页素材和第三方许可信息，约 8.65 MB。已经单独复制到空目录，在断网环境完成 50 关通关和音频、存档、触控检查，没有外部文件请求。不同文件路径的浏览器本地存档可能独立。

保留原作品的 50 个关卡、人物、箱子、墙壁、目标点，并接入原背景音乐和音效。原作品全部 8 个音频均已导出到网页素材目录，未使用的声音也保留。所有关卡均可选择。进度、最佳步数和当前游戏保存在浏览器本地，不依赖原作品的云变量。更换浏览器或网址后，存档不会自动同步。

## 操作

- 方向键或 WASD：移动。
- Z：撤回；Y：重做；R：重开；Esc：暂停/继续。
- 手机可用方向按钮或在棋盘上滑动。
- 默认关闭音效，可通过右上角按钮开启。

## 文件结构

- `web/`：可以独立复制的成品网页目录，发布到静态服务器也可使用。
- `web/session.js`：游戏状态、移动、撤回、重做和存档校验。
- `web/app.js`：界面、键盘、触控、音效和本地进度。
- `web/levels.js`：从原作品还原的 50 个关卡。
- `extracted/images/`：全部 145 个造型资源。
- `extracted/audio/`：全部 8 个音频资源。
- `extracted/logic/`：80 个角色和 3 个场景的原始积木 XML。
- `extracted/manifest.json`：角色属性、素材索引及原变量。
- `extracted/project-metadata.json`：原作品的项目配置、工具箱、场景顺序及其他元数据。
- `extracted/project.bcm`：从拆分文件重新组装的完整作品，经过与原 BCM 的逐项一致性校验。
- `extracted/audit.json`：资源哈希、提取数量和完整性校验结果。
- `extracted/levels.json`：地图宽高、墙壁、目标点、箱子、玩家初始位置和标准 XSB 地图。
- `scripts/extract.mjs`：可重复运行的 BCM 提取和关卡转换脚本。
- `unpacked/`：原 EXE 解包文件，保留作对照。

## 开发

需要 Node.js。首次运行 `npm install`，修改代码后运行 `npm run build`。

生成或更新单文件版：`npm run build:single`。修改源码后需要重新运行此命令，更新根目录 HTML。

```sh
npm run extract
npm run audit
npm run build
npm test
npm run test:browser
```

游戏采用 `miaoda-game-sokoban-core@0.1.1` 的不可变棋盘和移动规则，使用 `lucide` 图标。每次输入同步完成一次移动和推箱子判断；静态地图只在换关时创建，角色和箱子只在状态改变时更新。没有持续运行的游戏查询循环，撤回恢复完整的游戏快照。

原作品的坐标通过 XML 解析器逐个还原，支持两位数列坐标。标准棋盘增加一圈不可见的外部边界墙，保证原地图外不能移动；原地图内的墙壁、箱子、目标点及玩家位置保持一致。没有保留原播放器的社区、排行榜、云服务和运行时依赖。

## 验证

- 所有 50 个关卡通过格式和实体校验。
- 所有 50 个关卡通过求解、逐步回放和完整撤回验证。
- 碰撞阻挡、推动、通关、暂停、重做失效和存档恢复测试通过。
- Playwright 在浏览器中逐关通关所有 50 关，检查桌面、390px 和 320px 页面，验证选关、键盘、方向按钮、滑动、通关、撤回/重做、暂停、保存/刷新和图片加载。
- 所有 8 个音频通过浏览器解码检查，背景音乐暂停与静音检查通过。
- 提取后逐文件核对资源二进制和原始 XML，并将全部拆分内容重新组装，与原 BCM 的全部字段逐项比较一致。

`scripts/browser-check.mjs` 使用此电脑已安装的 Chromium 路径。其他电脑需调整 `executablePath`。截图、所有关卡的解及浏览器验证报告保存在 `qa/`。

原作品素材和关卡未改变权属。第三方代码的许可证见 `THIRD_PARTY_NOTICES.md`。
